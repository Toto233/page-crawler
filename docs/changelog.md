# 版本记录

## 1.0.0 · 首个版本

以当前完整实现作为项目的首个正式版本，不包含开发期间的中间版本。

- 连续三维弓形腿链、四段刚性骨长、独立交错迈步和支撑多边形判断。
- 鼠标追随、预测转向、到达后保持站姿，以及自主漫步。
- 近距离短促扑击、前腿抓握与口器开合，支持扑空、继续追赶和重新捕食。
- 随页面滚动保持身体、脚、目标和轨迹的坐标关系，支持暂停与后台恢复。
- 可恢复的 DOM 接触形变、文字碎片、独立控制面板、快捷键及油猴配置。
- 本地演示页、照片视频图册、中文学习与架构文档、参数说明、论文链接和参考图署名。
- 七组浏览器回归检查，以及项目链接、照片、视频和本地服务验证工具。

源码与选定的当前演示素材纳入 Git；开发依赖、原始录制、日志、测试输出和生成压缩包不纳入版本控制。
