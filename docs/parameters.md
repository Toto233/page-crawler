# 当前参数与调整约束

对应版本 **1.0.0**。x/y/z 和骨长均采用页面 CSS 像素尺度，角度为弧度，时间为秒；并非物理长度或生物测量单位。

## 外观与站姿

| 参数 | 当前值 | 入口与影响 |
| --- | --- | --- |
| 基准四段长度 | 52 / 66 / 68 / 10 | `skeleton.boneLengths`，三维刚性长度 |
| 四对腿长度倍率 | 1 / 1.06 / 0.84 / 0.96 | `skeleton.pairScales`，第三对较短 |
| 正常身体高度 | 18 | `skeleton.bodyHeight`，动态身体高度在 `body.z` |
| 相机距离 | 600 | `project`，越近透视越明显；必须大于所有关节高度 |
| 四对站姿角 | 0.38 / 0.93 / 1.78 / 2.57 | `restAngles`，左右镜像生成八条腿 |
| 四对落脚半径 | 158 / 166 / 130 / 150 | `restRadius` |
| 最大弓形弯折参数 | 2.85 | `solveLeg`，决定最小可闭合伸展范围 |
| 曲率分配 | 0.5 | `solveLeg` 的 fraction，中间方向使用半个弯折角 |

改腿长时必须一起检查 restRadius、最小伸展范围、落脚预测和捕食收腿幅度。脚距超出可达范围后，把末端直接覆盖成目标坐标会造成最后一段被拉长；固定骨长检查能发现这一问题。

## 行走与转向

| 参数 | 当前值 | 说明 |
| --- | --- | --- |
| 可调速度 | 0.3–2.5 | 控制面板，普通行走按此倍率缩放 |
| 基础最大前进速度 | 58 | 实际还受朝向、支撑和剩余距离限制 |
| 最大角速度 | 4.2 × speed | `tick`，实际还受姿态允许条件限制 |
| 停止范围 | 15 | 停步后短暂收稳，随后不继续迈步 |
| 新脚方向预测 | 转向误差最多 ±0.55 | `chooseFoothold` |
| 每步角位移上限 | 0.72 | 防止脚跨过邻脚的环绕次序 |
| 抬脚后的支撑余量 | ≥8 | `supportMargin(index)` |
| 身体移动支撑余量 | ≥3 | `poseAllowed` |
| 普通最多摆动脚 | 3 | 转身或收稳时最多 4 |
| 普通脚摆动时长 | 0.26 / 0.27 / 0.21 / 0.23 | 按腿对区分，再按速度倍率调整 |
| 时间差上限 | 0.04 | `tick`，避免长时间差造成一步跳变 |

## 快速扑击

| 参数 | 当前值 | 说明 |
| --- | --- | --- |
| 捕食距离 | 125 | 超出范围先行走 |
| 蓄力时间 | 0.18 | 八脚落地后向后收身，再迅速前扑 |
| 蓄力后移量 | 最多 22 | 支撑区域和腿的可达范围不足时减少后移，脚尖保持原地 |
| 蓄力压低量 | 8 | 正常高度 18 降至 10 |
| 蜷身量 | 0–1 | 髋部纵向间距收小 12%、横向收小 8%，腹部前收 6 |
| 空中展开时段 | 飞行前 45% | 蜷身量平滑降至 0，恢复完整姿态 |
| 飞行时长 | clamp(距离/820, 0.11, 0.17) | 正常速度时，实际距离为身体到口器对应落点 |
| 抛物线高度系数 | 34 | 衔接低姿态后，身体最高约 48 |
| 空中收腿系数 | 0.30 | 基础扇形偏移在飞行中收小 |
| 收腿最小伸展 | 94 × 腿对倍率 | 在髋—脚连线上限制可达距离 |
| 落地缓冲时间 | 0.10 | 压低量 6，再恢复 |
| 捕食抓握时间 | 0.75 | 前腿向内抓握、口器开合 |
| 恢复时间 | 0.20 | 结束或中断后恢复站姿 |
| 捕获判定半径 | 28 | 落地时当前鼠标相对锁定点的距离 |
| 冷却 | 2.2 | 从起跳开始计时 |
| 重新武装位移 | >65 | 当前鼠标与上次锁定点之间的距离 |

捕食阶段的时间倍率为 clamp(speed, 0.5, 1.6)，不会和行走倍率完全相同。捕食范围按后移前的位置判断，避免蓄力动作自行取消攻击。改飞行时长后应重新录制：太短会导致可见帧过少；太长会形成漂浮感。在距目标约 125 像素进入蓄力的固定 60 Hz 常速回放中，后移 22 像素后扑击，腾空测得约 0.167 秒、820 像素/秒。

## DOM 效果

力度范围 0.3–2；recover 模式约 2.2 秒回弹，collapse 模式保留形变，最多保留 64 个目标。`targetAt` 过滤可编辑内容、控件、媒体、固定导航及大型容器。改变效果应保持 `release` / `restore` 能撤销，不能通过删除或永久修改网页内容实现。
